### `03` — NLP & LLM Engineering

**Category:** Natural Language Processing · Language Models · AI Applications

Repository: [Natural Text Understanding](https://github.com/vasdev-tishika/Natural-Text-Understandingisme)

This repository explores multiple NLP and LLM-powered applications. The projects below are separated by use case rather than grouped into one generic NLP description.

#### A. Hugging Face Text-to-SQL

**Objective:** Translate natural-language questions into SQL queries, making structured data more accessible to users who may not know SQL syntax.

**Technical focus:** Natural-language understanding, language models, SQL generation, query validation and structured-data interaction.

**Use case:** A user asks a question about a database in plain English; the system aims to produce a corresponding SQL query.

#### B. LangChain MCQ Creator

**Objective:** Explore automated multiple-choice question generation from learning material using an LLM-oriented workflow.

**Technical focus:** LangChain, prompt design, text processing, question generation, answer options and educational AI.

**Use case:** Transform source material into practice questions that can support revision and self-assessment.

#### C. LLM-Powered Search Engine

**Objective:** Explore a search experience that uses language-model capabilities to help users retrieve and understand relevant information.

**Technical focus:** Search workflows, natural-language queries, document retrieval and LLM-generated responses.

**Use case:** Help users find useful information from relevant content without relying only on manually scanning documents.

*These descriptions represent the intended application areas; the actual implementations, libraries and completed features should be verified against each project's code.*
